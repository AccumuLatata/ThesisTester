**15s packet:** 23 studies / **944** cells (`manifest.yaml`).  
**Tick-gated VA packet:** 4 studies / **207** cells (`manifest_va.yaml`).  
Catalog is still 50 anchors; VA tokens are a different object and must not
share a YAML with 15s cores. Regenerated by `generate_program_b_yaml.py`.
Do not hand-edit token lists. `validate_program_b_yaml.py` expand-checks the
15s packet **and** the product locks (timezone, required partners, no VA
cores, no `dVWAP` partner, Wave 0 `[[]]`). A failed file is not printed as
`ok`.

```bash
python3 examples/studies/program_b/generate_program_b_yaml.py
PYTHONPATH=. python3 examples/studies/program_b/validate_program_b_yaml.py
```

Replace `dataset.path` (`data/mnq_15s.csv`) with the operator’s 15s Quantower HE
file before `study run`.
